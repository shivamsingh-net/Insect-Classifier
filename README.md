# insect-classifier

A product page I built for a made-up insect specimen shop, just to practice front-end layout and design. Not a real store, just a UI exercise.

## About

I wanted to try building something that felt more like a product/catalog page than a typical portfolio project — so I went with this idea of a shop selling mounted insect specimens, kind of like an old-school natural history display. The left side shows the scientific classification (class, order, family, etc.) and the right side has the product info, price, and an "add to collection" button instead of "add to cart."

## Built with

- HTML
- CSS

No frameworks, no JS libraries — just plain HTML and CSS to focus on layout and styling.

## Features

- Two-tone split layout, one side light and one side colored
- Classification list styled like a spec sheet
- Product details: locality, sex, size, price
- Toggle switches for viewing the antennae and underside (UI only for now, not wired up yet)
- Nav bar and search bar in the header

## Running it locally

```bash
git clone https://github.com/shivamsingh-net/insect-classifier.git
cd insect-classifier
```

Just open `index.html` in your browser after that. Nothing else needed.

## What I was practicing

- Doing a split-screen two-color layout
- Laying out a long list of data (the classification section) in a way that doesn't look cluttered
- Making custom toggle switches with CSS
- Getting the typography/spacing to feel intentional instead of default
